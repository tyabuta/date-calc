日付計算ツール
仕様

計算の仕様

このページは Zola が Markdown から生成しています。

入力の操作

  • 今日 ボタンで、その日付欄を今日の日付にします。
  • スライダーで日付や日数を1日ずつ動かせます。つまみを掴むほか、 フォーカスしてから矢印キーでも動きます。
  • 「日数を数える」のスライダーは終了日を動かします。開始日は変わりません。
  • スライダーの範囲は既定で ±365日ですが、それを超える日付を直接入力すると 自動的に広がります。つまみの位置が実際の値とずれることはありません。

日数の数え方

表示定義
大きな数字終了日 − 開始日 の絶対値。開始日当日は数えない
両端を含む日数上の値 + 1。「初日も最終日も数える」数え方
平日のみ両端を含む区間から土日を除いた日数。祝日は考慮しない
年月日の内訳下の「月をまたぐときの数え方」を参照

たとえば 4月1日から4月2日なら、差分は 1日、両端を含むと 2日 です。

月をまたぐときの数え方

「開始日と同じ日に到達した回数」で月数を数え、残りを日数にします。 終了日の日が開始日の日より小さければ、その月はまだ到達していないと見なします。

期間内訳
1月28日 → 2月28日1ヶ月
1月31日 → 2月28日28日
1月31日 → 3月1日1ヶ月1日

1月31日から2月28日を 1ヶ月 としない理由は、そうすると1月28日・29日・30日・31日の どれから数えても同じ 1ヶ月 になってしまい、区別がつかなくなるためです。 月の長さが一定でない以上どこかで妥協が要る部分なので、厳密さが必要なときは 大きく表示している「日数」を使ってください。

和暦

元号のテーブルは持たず、ブラウザ内蔵の和暦カレンダー (Intl.DateTimeFormat("ja-JP-u-ca-japanese")) に任せています。改元は年の途中で 起きるので、年ではなく日付で切り替わります。

日付和暦
1912年7月29日 → 30日明治45年 → 大正元年
1926年12月24日 → 25日大正15年 → 昭和元年
1989年1月7日 → 8日昭和64年 → 平成元年
2019年4月30日 → 5月1日平成31年 → 令和元年

明治6年(1873年)より前の日本は旧暦を使っていたため、それ以前の日付は 西暦との対応が単純ではありません。表示はしますが扱いには注意してください。

年齢

3つの数え方を出し分けています。

表示加算されるタイミング
満年齢誕生日当日。一般的な数え方
法律上の年齢誕生日の前日。年齢計算ニ関スル法律と民法143条による
数え年生まれた時点で1歳、以降は元日ごと

4月1日生まれが早生まれになるのは、法律上は3月31日に歳を取るためです。 学年の区切り（4月2日〜翌年4月1日生まれが同学年）もこれに対応しています。

2月29日生まれは、平年には応当日がないため2月28日に加算します （民法143条2項の「月の末日に満了する」に相当）。この場合は前日ではなく 末日そのものなので、満年齢と法律上の年齢が同じ日に上がります。

タイムゾーンの扱い

日付はすべて UTC の 0 時として解釈しています。ローカル時刻のまま引き算すると、 夏時間のある地域で 1 日ずれることがあるためです。入力した日付の見た目と 計算結果は常に一致します。

想定範囲

内部では JavaScript の Date を使っています。西暦 1000 年から 9999 年までは <input type="date"> 側の制約でそのまま扱えます。うるう年は自動的に考慮されます。
